Website Helpdesk Multi-Company

Versión 18.0.1.0.0

Descripción General

Publica en /helpdesk los equipos de soporte de todas las compañías de la base de datos, en un solo sitio web. El acceso a cada equipo se restringe según las compañías del usuario.

Comportamiento

  • /helpdesk muestra la lista de equipos con formulario web activo de todas las compañías (usando sudo para saltar la regla Team: multi-company).
  • Al entrar a un equipo se valida que su company_id esté en res.users.company_ids. Si lo está, se amplían las allowed_company_ids del contexto para que la regla de multi-compañía deje leer el equipo y sus campos SEO sin sudo.
  • Si el equipo pertenece a otra compañía, se muestra la página de acceso restringido en lugar de un error.

Alcance

Solo sobrescribe el controlador de website_helpdesk y agrega una plantilla de acceso restringido. No modifica modelos ni datos.

Dependencias

  • website_helpdesk
